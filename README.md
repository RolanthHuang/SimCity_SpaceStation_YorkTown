# Yorktown · 太空城市經營 v5.0.0

[直接開啟遊戲](https://rolanthhuang.github.io/SimCity_SpaceStation_YorkTown/)

在完整的環形城市臂建造、經營、步行與飛行，並走進重要建築的代表性大廳／控制室。

- 完整單臂 19,296 格，八區導航，首尾道路、水電與通勤連通。
- 人口、工作、稅收、預算、交通、公共服務、災害與電廠自動更新。
- 建築營運管理與設備升級，以及氧氣、散熱與生命維持設施。
- Walk／Fly 視角，十類重要建築可進入。
- 原創離線氛圍配樂，瀏覽器自動／手動保存、JSON 匯出與匯入。

## 操作

上方「環臂」可前往各區。F 切換步行，G 切換飛行，WASD 移動；步行 Space 跳躍，飛行 Space 上升、C 下降、Shift 加速。重要建築從檢視面板進入，或步行靠近按 E；室內 M 管理、E 返回街道。P 暫停／繼續；施工後按 1× 恢復經營。

## 離線與原始碼

下載 [完整遊戲與原始碼包](Yorktown-Habitat-Package.zip)，解壓後直接開啟 index.html。套件包含 SimCity 模組、測試、建置設定、Three.js、架構和操作說明。安裝開發依賴後可執行 npm run build 重新產生單檔網頁。

網站根目錄的 index.html 是完整離線建置，不依賴遠端素材服務。原本本機檔案／其他網站的瀏覽器存檔不會自動移到此網站；請從舊入口匯出 JSON，再在這裡匯入。可讀取 v4.0.x 懸臂存檔，不支援 v3 平面版存檔。

## 目前範圍

其他兩條城市臂和中央樞紐仍是景觀。室內為代表性可走動空間，並非每棟全部樓層；行人為代表性通勤人流。Fly 為觀察模式，沒有飛船碰撞。本版是瀏覽器原型，不是原版 SimCity 的功能或素材移植，也不是 App Store 成品。

53 項程式檢查通過。最後的短按移動鍵調整未完成瀏覽器複驗；滿城與手機效能尚未全面驗證。
